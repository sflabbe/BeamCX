# BeamCX v0.6.1

First public release of the standalone TI-Nspire CX CAS beam and rectangular-portal calculator.

- Four single-span beam presets, continuous beams and rectangular portals.
- Offline MANUAL, concrete RECT and steel IPE/HEA sections; independent portal Columns / Beam groups.
- Optional beam self-weight, continuous envelopes, portal member-force diagrams and magnified deformation.
- Full-precision input and explicit CAS export in separate namespaces.
- Strict saved-document format 0.6.1; documents from other versions reset to defaults without migration.
- Corrected closed moment-reference outlines in the portal selector.

Download **BeamCX.tns**, transfer it with N-Link Web using a simple filename in the calculator's root folder, and open it from My Documents. Do not use Upload OS for this document.

This is a teaching and engineering-check tool, not a design-code verifier. Read the [usage and limitations](../README.md) and [technical evidence](VALIDATION.md).
